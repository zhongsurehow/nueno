# 加密货币实时价格对比

这是一个实时虚拟货币价格对比网页应用，可以从多个主流交易所获取加密货币的价格数据，并进行对比分析。

## 功能特点

- 支持从Mexc、Gate、Kucoin、Bitget、Bybit、HTX、Binance和OKX等交易所获取价格数据
- 实时更新价格信息，支持自动刷新
- 价格高低差异可视化显示
- 支持按货币名称搜索
- 支持按各列排序
- 计算各交易所间的价格差异
- 响应式设计，支持移动设备

## 使用方法

1. 打开`index.html`文件在浏览器中查看
2. 使用搜索框搜索特定加密货币
3. 点击表头可以按不同列排序
4. 使用刷新按钮手动更新数据
5. 选择自动刷新间隔可以自动更新数据

## 技术说明

当前版本使用模拟数据进行演示。在实际应用中，需要通过后端服务来聚合各交易所的API数据，以避免跨域问题和保护API密钥等敏感信息。

### 实现真实API集成

要集成真实的交易所API，建议：

1. 创建一个后端服务（如Node.js、Python等）
2. 在后端服务中调用各交易所的API
3. 将聚合后的数据通过自己的API提供给前端
4. 修改前端的`fetchData`函数，调用自己的后端API

## 文件结构

- `index.html` - 网页主结构
- `styles.css` - 样式表
- `script.js` - JavaScript功能实现

## 注意事项

- 价格数据仅供参考，不构成投资建议
- 不同交易所的价格可能存在延迟
- 实际部署时需要考虑API访问频率限制
